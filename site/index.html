01The problem

Major upgrades get put off.

A bot can open the version bump. Finding what breaks, fixing it and proving it still works is left to people.

Swipe to see the whole sketch →

02The solution

One approval. Proof before merge.

Codebase Doctor maps every usage, plans the change, waits for your “approved”, and opens a pull request only when your own checks pass.

Swipe to see the whole sketch →

03Demo

Two minutes, start to finish.

04You stay in charge

Nothing changes until you say “approved”.

The server enforces it, not a prompt. Branch, patch and pull request refuse to run until you approve this exact plan, and no pull request opens until your checks pass.

checkout_branchrefused 
Migration plan b3b654d66018 has not been approved. Present the plan to the user; after they type "approved", call approve_migration_plan with { sessionId, planId: "b3b654d66018", confirmation: "approved" }.

07Get started

Runs locally, inside Bob.

terminal
$ git clone https://github.com/FayazNoor/Codebase-Doctor
$ cd Codebase-Doctor
$ npm install && npm run build
$ cp .bob/mcp.example.json .bob/mcp.json   # point it at backend/dist/index.js

then, in BobUpgrade react from 17 to 18.3.1 in https://github.com/<owner>/<repo>
